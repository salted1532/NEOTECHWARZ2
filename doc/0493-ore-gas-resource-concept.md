# 0493 - Ore/Gas 자원 명칭·컨셉 재정의 (확정)

## 요청 내용
"Ore 과 Gas의 번역작업을 해야하는데 현재 Gas의 경우 진짜 기체 Gas의 형식이 아니라 그냥 초록색 광물
덩어리란 말이야 이에 관해서 Ore와 Gas라는 두 자원의 명칭이랑 컨셉을 정해야할거 같아 Gas는 현재
지구로 치면 석유 같은 느낌인데 광물 형태인데 다른 명칭이랑 설정을 붙이고 Ore는 우리가 원하는대로
사용가능한 그러한 광물이라는 설정이랑 명칭도 붙이자 문서로 컨셉좀 정해줘"

## 조사 내용
- `ResourceType` enum(`Assets/Scripts/Resource/ResourceNode.cs:6`)에 `Ore`/`Gas` 두 값만 있고, 노드
  이름은 별도 로컬라이제이션 키 없이 `RTSUnitController.cs:2070`에서 `"Ore"`/`"Gas"` 문자열이
  그대로 하드코딩되어 있음 (doc/0490 패턴과 달리 name/desc 필드 자체가 아직 없음).
- `Assets/prefabs/Resource/Gas.prefab`의 실제 메시/오브젝트 이름은 `Gas`인데, 비주얼은 기체 이펙트가
  아니라 초록색 결정형(크리스탈) 메시 - 사용자 말대로 이름과 비주얼이 어긋나 있음.
- `게임설명서.md:110-111`에 "광물(Ore): 기본 채취 자원", "가스(Gas): 보조 자원"이라고만 되어 있고
  세계관 설정(왜 이런 자원인지)은 없음.
- NTA 진영 건물명(CommandCenter, SupplyDepot, Barracks, Factory, Spaceport, Lab)은 전부 수수한
  실존 군사/산업 용어 - 판타지풍 조어보다는 "그럴듯한 광물학 용어" 톤이 기존 세계관과 어울림.

## 컨셉 확정

### 아이로나이트 광석 (Ironite Ore) — 기존 "Ore"
- **명칭**: EN `Ironite Ore` / KR `아이로나이트 광석`
- **설정**: 행성 지각 어디서나 흔히 채굴되는 범용 금속광. 정제 방식만 바꾸면 장갑판이든 프레임이든
  회로든 탄약이든 뭐로든 가공할 수 있어서, NTA 모든 생산 라인(유닛·건물 가리지 않고)의 기초 재료로
  쓰인다 - "우리가 원하는 대로 쓸 수 있는 광물"이라는 요청 그대로 다목적 구조재 컨셉.
- `Iron`(철) 어원이 그대로 드러나 "흔한 금속광"이라는 정체성이 이름만 봐도 직관적으로 전달됨.

### 페트로나이트 (Petronite) — 기존 "Gas"
- **명칭**: EN `Petronite` / KR `페트로나이트` - `Petro-`(석유) + `-ite`(광물 접미사) 조합 조어.
- **설정**: 겉보기엔 초록빛 결정 광물이지만, 정제로에 넣으면 원유처럼 고에너지 연료·추진제·플라즈마
  충전재를 뽑아낼 수 있는 자원 - "지구로 치면 석유 같은 느낌인데 광물 형태"라는 요청을 그대로
  반영. 채굴 상태는 고체 결정인데도 여전히 "가스"라 불리던 이유는, 옛 개척단이 정제 후 뿜어져 나오는
  가연성 기체 산출물만 보고 자원 자체를 "가스"로 잘못 보고해 관습적으로 이름이 굳어버렸다는 설정을
  붙이면 기존 이름-비주얼 불일치도 세계관 안에서 자연스럽게 설명됨 (안 붙여도 무방한 선택 사항).
- 용도(게임플레이 포지션)는 기존 Gas와 동일 - 고급 유닛/건물, 특수 무기 등 소모가 큰 항목의 두 번째
  비용 자원.

## 향후 구현 범위 (명칭 확정, 실제 구현은 별도 doc으로 진행)
이번 문서는 컨셉/명칭만 정리 - 코드 변경 없음. 사용자가 Ironite Ore(아이로나이트 광석)/
Petronite(페트로나이트)로 확정함. doc/0490과 동일한 패턴으로 별도 제안 문서를 만들어 진행 예정:
- `ResourceNode`/`ResourceManager`에 `itemID`/`description` 필드 추가 (또는 `ResourceType` 자체를
  키로 사용)
- `RTSUnitController.cs:2070`의 하드코딩 `"Ore"`/`"Gas"` 문자열을
  `LocalizationManager.GetTextOrFallback` 호출로 교체
- `ko.json`/`en.json`에 `resource.ore.name/.desc`, `resource.gas.name/.desc` 4개 키 추가
- `게임설명서.md` 5장 자원 설명 갱신
- (선택) 프리팹/에셋 파일명을 `Ore.prefab`/`Gas.prefab` → `Ironite.prefab`/`Petronite.prefab`으로
  리네임할지는 별도 결정 필요 (내부 참조가 많아 리스크 대비 이득이 크지 않으면 파일명은 유지하고
  표시 텍스트만 바꾸는 쪽을 권장)

## 요약
Ore→아이로나이트 광석(Ironite Ore, 범용 구조재), Gas→페트로나이트(Petronite, 석유 아날로그
연료광물)로 명칭·컨셉 확정. 다음 단계는 실제 로컬라이제이션 키 추가·코드 변경 제안 문서(doc/0490
패턴)로 진행.
