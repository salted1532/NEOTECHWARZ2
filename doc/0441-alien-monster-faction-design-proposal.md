# 0441. 외계 몬스터 종족(3유닛/3건물) 디자인 제안

**날짜**: 2026-08-06

## 요청 내용

멀티플레이는 고려하지 않는 전제 하에, 새로운 외계 종족을 디자인. 조건은 다음과 같음.

- 유닛 3종: 근접 / 원거리 / 공중
- 건물 3종: 메인기지 / 유닛 생산 건물 / 에너지 코어
- 인간형(지능형) 디자인이 아니라 **괴물형(몬스터)** 디자인
- 유닛 이름, 공격력, 체력 등 스탯을 포함한 기획 문서 작성

## 조사 내용

기존 데이터 스키마와 밸런스 기준선을 잡기 위해 다음을 확인함.

- `Assets/Scripts/ScriptableObject/UnitDataSO.cs`, `BuildingDataSO.cs`: 유닛/건물 스탯 필드 구조 (`hp`, `attackDamge`, `attackRange`, `attackSpeed`(공격 간격), `armorType`(Light/Heavy), `sizeType`(Small/Medium/Large), `canAttackGround/Air`, `attackDelivery`(Hitscan/Projectile), `mineral/gas/population/productionTime`, `requiredBuildingID` 등)
- `NTA Unit/Building Data SO.asset`, `OC Unit/Building Data SO.asset`: 기존 두 종족(NTA=인간 진영, OC=NTA를 미러링한 사이보그 적 진영)의 실제 스탯 값. OC는 NTA와 완전히 동일한 수치를 재스킨한 것으로, 이번 신규 종족은 그 패턴을 따르지 않고 **3유닛/3건물 전용 밸런스**로 새로 설계함.
- `Assets/Scripts/Unit/DamageTypes.cs`: `ArmorType { Light, Heavy }`, `SizeType { Small, Medium, Large }`

이 종족은 티어(생산 건물 3종 계층 구조) 없이 건물 1개(산란구덩이)가 근접/원거리/공중을 전부 생산하는 구조이므로, NTA 1티어 유닛(체력 40~75, 공격력 5~10)과 2티어 유닛(체력 125~180, 공격력 6~20)의 중간값 근처로 잡아 "적은 유닛 수로도 제 역할을 하는" 밸런스를 노림. 방어 타입은 3종 모두 Light(경장갑)로 통일해 "물량과 기동성은 강하지만 관통 공격에 취약한 괴물 무리"라는 정체성을 스탯으로 뒷받침함.

## 설계안: 스포어 브루드 (Spore Brood)

### 컨셉

지능형 문명이 아니라 포자로 뒤덮인 행성에서 자생한 **집단 본능(하이브 마인드)** 생물군. 개체는 단순하지만 무리 지어 압박하며, 건물조차 금속이 아닌 살아있는 생체 조직으로 이루어져 있음(성장/재생 이미지). 인간형 실루엣을 피하고 곤충·기생생물·파충류가 뒤섞인 형태로 디자인.

### 유닛 (3종)

| 항목 | 립팽 (Ripfang) — 근접 | 스피터 (Spitter) — 원거리 | 스키터윙 (Skitterwing) — 공중 |
|---|---|---|---|
| 컨셉 | 날카로운 턱으로 물어뜯는 저비용 돌격 개체. 무리로 찍어 눌러야 하는 전위 | 부식성 체액을 뱉어내는 원거리 저격 개체 | 하늘을 뒤덮는 기생 비행체. 치고 빠지는 견제형 |
| 장갑/크기 | Light / Small | Light / Medium | Light / Medium |
| 체력(hp) | 60 | 50 | 65 |
| 공격력(attackDamage) | 9 | 11 | 8 |
| 사거리(attackRange) | 2 (근접) | 13 | 11 |
| 공격 간격(attackSpeed) | 0.5 (빠름) | 1.1 | 0.9 |
| 대지/대공 | 대지만 | 대지+대공 | 대지+대공 |
| 공격 전달 방식 | Hitscan (물어뜯기) | Projectile (산성 침) | Projectile (독침) |
| 비용 (mineral/gas/population) | 45 / 0 / 1 | 80 / 20 / 2 | 95 / 35 / 2 |
| 생산 시간 | 10 | 20 | 26 |
| 생산 건물 | 산란구덩이 | 산란구덩이 | 산란구덩이 |

- **립팽**: 가장 저렴하고 빠르게 뽑아 물량으로 밀어붙이는 유닛. 체력·공격력 모두 낮지 않지만 사거리가 근접뿐이라 원거리 화력에 약함.
- **스피터**: 세 유닛 중 가장 낮은 체력의 글래스캐논. 대지/대공을 모두 커버해 이 종족의 주력 딜러 역할.
- **스키터윙**: 유일한 공중 유닛. 대지/대공 모두 공격 가능해 정찰 겸 견제 역할을 겸함. 방어형 유닛이 따로 없는 종족 특성상 스키터윙의 기동력이 대공 방어의 핵심.

### 건물 (3종)

| 항목 | 하이브 코어 (Hive Core) — 메인기지 | 산란구덩이 (Spawning Pit) — 유닛 생산 | 바이오리액터 (Bio-Reactor) — 에너지 코어 |
|---|---|---|---|
| 컨셉 | 종족의 심장부. 살아있는 구조물로 서서히 자연 재생(바이오 리제너레이션) | 립팽/스피터/스키터윙을 모두 생산하는 단일 생산 시설 (티어 구분 없음) | 생체 에너지를 공급하는 기관. 인구수(보급) 공급을 겸함 |
| 크기(Size) | 4x4 | 3x3 | 2x2 |
| 체력(hp) | 1600 | 900 | 700 |
| 비용 (mineral/gas) | 400 / 0 (시작 건물) | 150 / 50 | 150 / 0 |
| 인구 공급(maxpopulationamount) | 10 | 0 | 8 |
| 건설 시간 | 60 | 40 | 30 |
| 선행 건물 | 없음 | 없음 | 없음 |

- **하이브 코어**: 세 건물 중 가장 튼튼함(1600). "살아있는 본진"이라는 컨셉을 살리려면 초당 소량의 자연 체력 재생이 필요한데, 이는 현재 `BuildingData`/`HealthManager` 스키마에 없는 기능이라 별도 구현이 필요함(아래 남은 작업 참고).
- **산란구덩이**: NTA/OC가 병영·공장·우주공항으로 나눈 생산 계층을 이 종족은 건물 하나로 압축. 그만큼 파괴됐을 때 종족 전체의 유닛 생산이 완전히 멈추는 리스크를 짊어짐.
- **바이오리액터**: 이름상 "에너지 코어"지만 실제로는 보급(인구) 공급 + 자원(gas 역할) 공급을 겸하는 것으로 설계. 파괴 시 페널티(생산 속도 저하 등)를 주고 싶다면 이것도 별도 로직이 필요함.

## 남은 작업 (구현 전 확인 필요)

이 문서는 스탯/컨셉 기획안이며, 아직 프로젝트 코드나 에셋은 변경하지 않았음. 실제로 게임에 넣으려면:

1. `EnemyUnitDataSO` / `EnemyBuildingDataSO`(또는 신규 SO) 에셋에 위 표 값을 입력
2. 3개 유닛 + 3개 건물 프리팹/모델/아이콘/사운드뱅크 제작
3. 하이브 코어의 "자연 재생" 로직 — 신규 기능이므로 `HealthManager` 확장 필요
4. 바이오리액터 파괴 시 페널티를 넣을지 여부 결정(넣는다면 신규 로직 필요, 안 넣으면 순수 인구/자원 공급 건물로 단순 처리)
5. 이 종족을 어떤 스테이지에 어떻게 배치할지(기존 NTA/OC와 별개 진영으로 등장하는지, 특정 스테이지 전용 적으로만 쓰는지)

수치나 컨셉에 수정하고 싶은 부분이 있으면 먼저 조정하고, 위 항목을 실제로 구현할지 확인해서 진행하겠음.
