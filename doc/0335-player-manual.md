# 0335. 플레이어용 게임 설명서 작성

**날짜:** 2026-07-31

## 요청

> 메인화면 -> 시작(튜토리얼 스테이지0으로 이동) -> 설정(소리설정만 가능) -> Exit 게임 종료 / 스테이지0
> 주목표/서브목표(옵션 소리설정 + 메인화면이동) / 주목표 완료시 승리화면 -> 메인화면 or 다음 스테이지
> / 다음스테이지 -> 자유모드(승리 목표 없음, 자유롭게, 옵션 소리설정 + 메인화면이동) — 이제 프로토타입
> 버전은 구성한거 같은데 현재 버전에서 게임 설명서 같은 느낌으로 플레이 방법, 기능별 조작방법, 게임의
> 목표등을 정리한 문서를 하나 만들어줄래?

## 작업 내용

`Docs/`(스크립트별 개발자 문서)와는 별개로, 플레이어가 읽을 설명서를 프로젝트 루트에
`게임설명서.md`로 새로 작성. 사용자가 요약해준 메뉴/스테이지 흐름을 뼈대로 삼되, 조작법/유닛·건물
목록/자원/점령·영토/시야 등 세부 내용은 짐작하지 않고 실제 코드에서 조사해서 채워 넣음(fork로 조사만
먼저 수행 - `UserControl.cs`의 키 입력, `RTSUnitController`의 UnitID/BuildingID 상수 + 실제
표시명(`NTA Unit/Building Data SO.asset`), `ResourceManager`, `CaptureSystem`/`TerritoryZone`,
`Stage0Objectives`/`VictoryPanelController`, `MainMenuController`, 사운드 설정 패널 등).

## 문서 구성

1. 게임 소개
2. 시작하기(메인 화면 - 시작/설정/Exit)
3. 기본 조작법(마우스, 유닛 명령 단축키, 건설 메뉴 단축키, 부대 지정/컨트롤 그룹)
4. 자원과 인구수
5. 건물 목록(6종)
6. 유닛 목록(9종) + 특성 선택 시스템(샤프슈터/스카이랜서/가디언 드론 스킬 예시)
7. 점령과 영토
8. 시야와 안개(Fog of War)
9. 스테이지 진행(스테이지0 주/서브목표 + 승리화면 → 다음 스테이지=자유모드/SampleScene, 승리조건 없음)
10. 옵션(사운드만, 다른 설정 항목 없음)
