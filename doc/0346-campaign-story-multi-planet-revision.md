# 0346 — 캠페인 스토리 다중 행성계 확장 제안

## 요청

사용자가 `Docs/Campaign.md`의 캠페인 스토리가 전부 "프로메테우스" 단일 행성에서 벌어지는 현재 구조 대신, 은하계/행성계 스케일로 각 스테이지(미션)마다 서로 다른 행성에서 사건이 벌어지는 느낌으로 바꾸는 게 좋겠다고 제안. [[confirm_before_implementing]] 규칙에 따라 실제 `Docs/Campaign.md` 수정 전에 변경안을 문서로 먼저 제시.

## 현재 구조 (Before)

`Docs/Campaign.md` 전체가 "프로메테우스" 행성 하나를 무대로 진행됨:
- 세계관 문단: "두 세력은... 거대 광맥을 지닌 행성 **프로메테우스**를 두고 충돌한다. 그리고 그 행성에서... 외계종족과 마주하게 된다."
- Boot Camp, 미션 1~3 브리핑에서 모두 "프로메테우스 행성"을 직접 언급.
- 미션 4~5는 명시적 행성명은 없지만 문맥상 계속 같은 자리(프로메테우스 인근)로 읽힘.
- 미션 5에서만 워프 게이트를 통해 외계 모행성으로 이동 — 유일한 "다른 장소" 전환.

## 제안 구조 (After) — 프로메테우스 성계, 미션별 다른 행성

"프로메테우스"를 행성 하나가 아니라 **성계(항성계) 이름**으로 재정의하고, 그 안에 여러 행성/위성을 두어 미션마다 무대를 옮기는 방식.

| 단계 | 무대 (행성/위성) | 비고 |
|---|---|---|
| Boot Camp | **프로메테우스 성계 — NTA 전방 기지 행성 (가칭 "아르카디아")** | NTA가 이미 개척한 거점. 튜토리얼이므로 기존 텍스트 거의 유지, 지명만 교체 |
| 미션 1: 국경 분쟁 | **프로메테우스-2 "테라니스"** (고밀도 광맥 행성) | 기존에 "프로메테우스"로 불리던 자원 행성. NTA·OC 최초 충돌 |
| 미션 2: 미지의 신호 | **프로메테우스-4 "아케론"** (죽은 위성, 고대 유적) | 광맥 행성과는 별개의 위성에서 유물 발견 → "성계 전체가 무대"라는 인상을 주는 핵심 전환점 |
| 미션 3: 침공 | **프로메테우스-3 "칼립소"** (OC 산업 식민지) | 외계종족이 먼저 초토화시킨 OC 주력 식민지. 자원 행성과 다른 곳이라 피해 규모가 뒤늦게 드러나는 서스펜스 강화 |
| 미션 4: 공동 전선 | **아케론 궤도 / 성계 공동 전선 기지** | 미션2의 유적 위성 궤도상에 NTA+OC 연합 기지 구축 — 성계 내 여러 격전지를 정리하는 최종 방어전 |
| 미션 5: 최후의 원정 | **성계 밖 — 워프 게이트 너머 외계 모행성** | 기존과 동일하게 성계를 벗어난 이동으로 유지 (이미 "다른 장소"였음) |

### 세계관 문단 수정 방향

기존: "두 세력은... 행성 **프로메테우스**를 두고 충돌한다. 그리고 그 행성에서... 외계종족과 마주하게 된다."

수정안: "두 세력은... **프로메테우스 성계**의 자원을 두고 충돌한다. 여러 행성과 위성에 흩어진 채 전선이 확대되던 중, 그 성계 한켠의 죽은 위성에서... 외계종족의 흔적과 마주하게 된다."

### 각 미션 브리핑 텍스트 변경 범위

- Boot Camp / 미션 1~3의 대사 중 "프로메테우스 행성" 표현을 각 미션의 새 행성명으로 교체 (예: "프로메테우스 행성에 온 것을 환영한다" → "테라니스에 온 것을 환영한다" 또는 "프로메테우스 성계, 테라니스 행성에 온 것을 환영한다" 식으로 성계+행성 병기).
- 미션 3 브리핑에서 "OC 점령 지역 전체"가 칼립소를 가리키도록 자연스럽게 문구 보강 (예: "OC 산업 식민지 칼립소 전역에서 구조 요청이...").
- 미션 4는 새로 "아케론 궤도 공동 기지"라는 장소감을 대사에 한 줄 추가할지 여부 — 최소 변경이면 생략 가능.
- 미션 5는 기존 텍스트 그대로 유지 (이미 성계 밖으로 나가는 구조).

### 행성명 (가칭) 목록

- 아르카디아 (Arcadia) — Boot Camp, NTA 전방 기지 행성
- 테라니스 (Terranis) — 미션 1, 광맥 자원 행성
- 아케론 (Acheron) — 미션 2, 죽은 위성/고대 유적
- 칼립소 (Calypso) — 미션 3, OC 산업 식민지

행성명은 가칭이며 사용자가 다른 이름을 원하면 교체 가능.

## 변경 범위

- **수정 대상**: `Docs/Campaign.md` (세계관 문단, Boot Camp~미션3 브리핑 중 지명 언급 부분)
- 미션 4, 5는 최소 수정 또는 무변경
- 메인/서브 목표 리스트 자체는 변경하지 않음 (스토리 무대만 확장)

## 사용자 결정 및 실제 반영

사용자가 무대 구조(성계 안에 미션별로 다른 세계)는 승인했으나, 행성명은 "아직 안 정하고 그냥 전체 스토리만 변경"해달라고 함. 이에 따라 위 제안의 가칭 행성명(아르카디아/테라니스/아케론/칼립소)은 사용하지 않고, `Docs/Campaign.md`를 **역할 기반 서술**(예: "프로메테우스 성계", "자원 행성", "성계 외곽의 죽은 위성", "OC의 주력 식민 행성")로 수정.

### 실제 변경 (Docs/Campaign.md)

- 세계관 문단: "행성 프로메테우스를 두고 충돌" → "프로메테우스 성계로 진출하며 충돌", 성계 안에 자원 행성/OC 식민 행성/죽은 위성 등이 흩어져 있다는 문장 추가. "행성/위성 이름은 아직 미정 (추후 확정)" 안내 문구 삽입.
- Boot Camp 브리핑: "프로메테우스 행성에 온 것을 환영한다" → "프로메테우스 성계, 우리의 전방 기지 행성에 온 것을 환영한다."
- 미션 1 브리핑: "프로메테우스 행성에서 대규모 광맥이 발견" → "성계 내 자원 행성에서 대규모 광맥이 발견".
- 미션 2 브리핑: 유물 발견 장소를 "성계 외곽의 죽은 위성"으로 명시.
- 미션 3 브리핑: "OC 점령 지역 전체" → "OC의 주력 식민 행성 전역"으로 구체화.
- 미션 4, 5는 원안대로 변경 없음 (미션 5는 이미 성계 밖 워프 게이트 이동 구조).

## 비고

코드 변경 없음, `Docs/Campaign.md` 문서만 수정. 행성 고유명사는 추후 사용자가 정하면 다시 치환 필요.
