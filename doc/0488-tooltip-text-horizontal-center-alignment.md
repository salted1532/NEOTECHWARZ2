# 0488 - 건설모드 툴팁 이름/설명 텍스트 가운데 정렬

## 요청 내용
"건설 모드의 건물 마우스 호버시 Tooltip에 경우 설명이랑 이름을 가운데 정렬 시켜야할거 같아
아직도 왼쪽으로 너무 치우쳐져 있어" - doc/0486에서 텍스트 박스 자체의 오프셋(패널 밖으로 15px
튀어나가던 것)은 고쳤지만, 박스 "안"에서 글자가 정렬되는 방식은 안 건드렸어서 여전히 왼쪽으로
쏠려 보이는 문제.

## 원인
`GameManager.prefab`의 툴팁 `TitleText`/`DescriptionText` 두 TMP 컴포넌트 모두
`m_HorizontalAlignment: 1`(Left)로 되어 있었음. doc/0486에서 고친 건 "박스의 위치"(패널 안에서
가운데로 이동)였지, "박스 안에서 글자가 어느 쪽으로 붙는지"는 별개 설정이라 그대로 남아있었음.

비용 없는 툴팁(이동/공격 등)은 `TooltipContentFitter`가 박스 폭 자체를 텍스트 길이에 맞춰
줄여버려서(`ContentSizeFitter.PreferredSize`) 박스와 글자 폭이 거의 같아 왼쪽 정렬이어도 티가 안
났음. 건설모드처럼 비용이 있는 툴팁은 박스 폭이 패널 폭(200)으로 고정돼 있는데(비용 아이콘 3줄
레이아웃이 고정 좌표라 doc/0471), 그 안에서 "Barracks"처럼 짧은 텍스트가 왼쪽 정렬되니 박스는
가운데인데 글자만 왼쪽으로 쏠려 보였던 것.

## 수정
`GameManager.prefab`의 `TitleText`/`DescriptionText` 두 TMP 컴포넌트의
`m_HorizontalAlignment`을 `1`(Left) → `2`(Center)로 변경. 비용 없는 툴팁은 어차피 박스가 글자에
딱 맞게 줄어들어 있어서 가운데 정렬로 바꿔도 시각적으로 아무 차이 없음 - 두 경우 모두 안전.

## 확인
프리팹의 두 대상 컴포넌트(fileID 6111134133906253754=TitleText,
809641165462683610=DescriptionText)에만 정확히 적용됐는지 각각의 `m_GameObject` 참조로 직접
대조 확인. 컴파일 확인 완료(에러 0).
