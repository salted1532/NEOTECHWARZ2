# 0297 — 캠페인 스토리 문서 추가

## 요청

사용자가 Boot Camp + 미션 1~5의 브리핑/목표 텍스트와, "NTA vs OC 자원 경쟁 → 외계종족 발견 → 양측 공격받음 → 협력 → 외계종족 모행성 공략"으로 이어지는 5막 구조, 그리고 과거 기획서("네오테크 워즈: 인류의 분열")를 참고자료로만 제공하며 `Docs` 폴더에 캠페인 스토리 문서로 정리해달라고 요청.

## 변경 내용

- **신규**: `Docs/Campaign.md` — 세계관 요약, 세력(NTA/OC) 소개, 5막 구조표, Boot Camp + 미션 1~5의 브리핑 대사·메인/서브 목표 전문.
- 과거 기획서는 세력명/지휘관명만 재사용하고 스토리는 새 캠페인이라는 점을 문서 상단에 명시.
