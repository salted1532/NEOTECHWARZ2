# 0604 — 캠페인 행성 이름 반영 & 미션5 브리핑 모순 수정

날짜: 2026-08-18

## 요청 내용

`doc/0603`에서 제안한 행성/위성 이름과 서브미션1·2 무대 컨셉을 `Docs/Campaign.md`에 실제로 반영하고,
각 미션의 무대 위치 설명도 추가. 추가로 미션5는 사용자가 적어둔 "인간이 만든 위성 플랫폼(외계 지휘 코어가
자리 잡은 위성)"이라는 설정에 맞춰 브리핑 대사 중 이질적인 부분을 수정.

## 조사 내용

미션5 브리핑 대사(수정 전)는 "거대한 워프 게이트가 열렸고 그 너머 모행성으로 진입한다"는 내용이었는데,
이는 미션5 제목 밑에 사용자가 적어둔 위치 설명("인간이 만든 위성 플랫폼에 외계 지휘 코어가 자리 잡음")과
맞지 않음 — 워프 게이트 너머 미지의 모행성이 아니라, 원래 인간이 만든 기존 시설(위성 플랫폼)이 점거당한
상황이어야 함. 이 모순을 없애기 위해 "워프 게이트/모행성" 서사를 걷어내고, 제우스 플랫폼(원래 NTA 관측
기지였다가 점거당함)을 정면 목표로 삼는 서사로 교체. 같은 이유로 5막 요약 표와 "한 줄 요약" 줄의
"외계종족 모행성 공략" 표현도 "외계 지휘 플랫폼 공략"으로 함께 정리.

```

| 이름 | 위치·지형 | 비고 |
|---|---|---|
| 데메테르 (Demeter) | 초원 + 바다 | NTA 전방 기지이자 신규 광맥 발견지 — 튜토리얼·미션1 |
| 아레스 (Ares) | 죽은 위성, 붉은 캐니언 지형 | 외계 유물이 최초로 발견된 곳 — 미션2 |
| 칼립소 (Calypso) | 사막 행성 | OC 주력 식민지, 외계종족의 첫 대규모 공격 지점 — 미션3 |
| 에리스 (Eris) | 자갈+흙 지형 + 바다 | 외계 사령기지 위치, NTA-OC 최초 공동작전지 — 미션4 |

```

### 2) 5막 요약 표 / 한 줄 요약 — "모행성" → "지휘 플랫폼"으로 정리

기존: `| 5막 | 외계종족의 모행성으로 진격, 최종 격퇴 |`
변경: `| 5막 | 외계 지휘 코어가 있는 점거 플랫폼으로 총공세, 지휘 체계 궤멸 |`

기존: `한 줄 요약: ... → 외계종족 모행성 공략.`
변경: `한 줄 요약: ... → 외계 지휘 플랫폼 공략.`

### 4) 미션5 브리핑 대사 — 워프게이트/모행성 서사 제거

기존 코드:
```
> **부관**: "외계 함대는 후퇴했지만, 거대한 워프 게이트가 열렸습니다. 그 너머에서 놈들의 모행성이 확인되었습니다."
>
> **셀레나 카터 (통신)**: "OC 함대는 별도 경로로 모행성 후방을 친다. 정면은 NTA가 맡아라."
>
> **아드리안**: "알겠다. 이번엔 우리 단독이다."
>
> **부관**: "OC 지상 병력의 지원은 없습니다. 이번 작전은 NTA 단독으로 진행됩니다."
>
> **아드리안**: "상관없다. 모든 함대, 워프 게이트로 진입한다."
```

변경 코드:
```
> **부관**: "외계 함대는 후퇴했지만, 놈들이 점거한 제우스 플랫폼에서 대규모 지휘 신호가 감지되고 있습니다. 원래는 우리 측 관측 기지였습니다."
>
> **셀레나 카터 (통신)**: "그 신호가 놈들의 지휘 코어다. OC 함대는 별도 경로로 플랫폼 후방을 친다. 정면은 NTA가 맡아라."
>
> **아드리안**: "알겠다. 이번엔 지상은 우리 단독이다."
>
> **부관**: "OC 지상 병력의 지원은 없습니다. 이번 상륙 작전은 NTA 단독으로 진행됩니다."
>
> **아드리안**: "상관없다. 전 함대, 플랫폼으로 진입한다."
```

이후 "이번 작전의 목표는 외계 지휘 체계의 완전한 파괴입니다." / "오늘, 이 전쟁을 끝낸다." 대사와
메인 목표(에너지 코어 3개 파괴 / 외계 지휘 코어 제거)는 새 설정과 그대로 부합해 변경 없음.

## 요약/남은 작업

`Docs/Campaign.md`에 확정된 행성 5개 이름을 반영하고, 각 미션·서브미션 위치 태그에 행성명+설명을 추가.
서브미션1(레이더 기지)·서브미션2(회색 위성+기계 잔해) 컨셉도 반영. 미션5는 "인간이 만든 위성 플랫폼이
점거당함"이라는 설정에 맞춰 브리핑 대사와 5막 요약/한줄요약의 "모행성" 표현을 모두 정리해 모순 제거.
스테이지 1~5의 실제 맵(지형)은 변경하지 않음.
