# 0423. 부대선택 버튼이 가끔 눌리지 않는 문제 - 원인 분석 및 수정

- 날짜: 2026-08-04

## 요청 내용

> 부대 지정시 각 부대별 부대선택 버튼이 제대로 작동을 안해 눌러도 선택이 안되는경우가 있고 어느때는 작동할때가 있어

## 조사 내용

`Assets/Scripts/UI/ControlGroupPanel.cs`의 `Update()`는 **매 프레임** 0~9번 부대(컨트롤 그룹) 전부에 대해
`PurgeAndCountControlGroup()`으로 인원수를 확인하고, 인원이 생기거나(0→N) 전멸하면(N→0) 그 즉시
버튼을 `Instantiate`/`Destroy`하고, 하나라도 바뀌면 남아있는 모든 버튼의 `SetSiblingIndex`를 다시 매겨
`HorizontalLayoutGroup`이 왼쪽부터 재배치하도록 만든다.

문제는 이 재구성이 "지금 유저가 마우스 버튼을 누르고 있는 중"인지 전혀 확인하지 않는다는 점이다.
Unity UI의 클릭 판정은 **PointerDown 시점에 맞은 오브젝트(`pointerPress`)**와 **PointerUp 시점에
그 좌표에서 새로 레이캐스트한 오브젝트**가 같아야 `onClick`이 발동한다. 그런데 실제 게임 플레이 중에는
```
유닛이 죽어서 다른 부대의 인원이 0이 됨 → 그 부대 버튼 Destroy → 남은 버튼들 왼쪽으로 SetSiblingIndex 재배치
```
가 전투 중에는 수시로 일어난다. 만약 유저가 부대선택 버튼을 누르고 있는 바로 그 프레임에(마우스
다운~업 사이) **다른** 부대가 전멸해서 이 재배치가 실행되면:

- 클릭 중이던 버튼 자신이 옆으로 밀려서, 마우스를 뗄 때 그 좌표에는 이미 그 버튼이 없어 클릭이 무효 처리되거나,
- (더 드물게) 버튼이 Destroy→Instantiate로 교체되면서 `pointerPress`가 가리키던 오브젝트 자체가 사라져 클릭이 무효 처리된다.

즉 "가끔 눌리는데 가끔 안 눌리는" 것은 무작위가 아니라, **누르는 순간 다른 부대의 인원 변화(전멸/생성)와
겹쳤는지 여부**에 따라 갈리는 것으로 보인다. 전투가 잦은 상황일수록(부대원이 자주 죽는 상황일수록)
이 창이 자주 열려 재현 빈도가 올라간다.

### 실제 확인한 것 / 확인 못한 것

Unity 에디터를 Play 모드로 띄워 실제로 부대를 2~3개 구성하고 버튼을 클릭해봤을 때는(다른 부대의
인원 변화가 그 프레임에 겹치지 않는 "평상시" 상황) 클릭이 항상 정상적으로 부대를 선택했다 - 즉
버튼 자체의 로직(`SelectControlGroup`)이나 다른 UI(정보창/생산대기열 패널 등)가 버튼을 가리는 문제는
아니었다. 다른 부대가 "정확히 클릭하는 그 프레임"에 전멸/재생성되는 경쟁 상태까지는 자동화 도구로
같은 프레임에 맞춰 재현하지 못했지만(엔진 프레임 단위로 두 이벤트를 동시에 넣을 방법이 없었음),
코드상 이 창이 열려있다는 것 자체는 명확하다.

## 코드 변경 (적용됨)

마우스 좌클릭을 누르고 있는 동안(다운~업 프레임 포함)은 버튼 생성/파괴/재배치를 잠깐 미루면
클릭 도중 버튼이 움직이거나 사라지는 일 자체가 없어진다. 한 프레임 정도 늦게 반영돼도(전멸/생성
직후 버튼이 눈에 보이는 시점이 최대 1프레임 늦어짐) 체감상 차이는 없다.

**기존 코드** (`Assets/Scripts/UI/ControlGroupPanel.cs`):
```csharp
    private void Update()
    {
        if (rtsController == null || buttonPrefab == null || buttonContainer == null)
            return;

        bool changed = false;
```

**변경 코드**:
```csharp
    private void Update()
    {
        if (rtsController == null || buttonPrefab == null || buttonContainer == null)
            return;

        // 좌클릭 중(다운~업)에는 버튼 생성/파괴/재배치를 미룬다 - 클릭 도중 다른 부대가 전멸/생성돼
        // 버튼이 옆으로 밀리거나 통째로 교체되면, 마우스를 뗄 때 그 자리에 클릭 대상이 없어 선택이
        // 씹히는 문제가 있었다(부대선택 버튼이 "가끔" 안 눌리던 원인).
        if (Input.GetMouseButton(0) || Input.GetMouseButtonUp(0))
            return;

        bool changed = false;
```

## 요약 / 영향받는 파일

- 원인: `ControlGroupPanel.Update()`가 마우스 클릭 중 여부와 무관하게 매 프레임 버튼을 생성/파괴/재배치해서, 클릭 도중(다운~업 사이) 다른 부대의 인원 변화와 겹치면 클릭 대상이 이동/소멸해 클릭이 무효화될 수 있었다.
- 수정: 좌클릭이 눌려있거나 막 떼진 프레임에는 버튼 재구성을 건너뛴다(1줄 가드).
