# 0578. README 로드맵 동기화 + 미문서화 스크립트 Docs 추가

**날짜:** 2026-08-14

## 요청 내용

사용자가 그동안 진행한 작업의 체크리스트(대부분 ✓ 완료 표시, 일부 미착수 항목 포함)를 통째로 붙여넣고 다음을 요청:
1. "현재 진행된 내용 Readme파일에다가 갱신해줘 이건 오늘 0.1.2버전의 버그들을 고친 내용들이야"
2. "이것도 참고해서 로드맵 갱신해주고 매번하는거처럼 새로운 스크립트가 추가된게 있으면 정리한 문서를 Docs에다가 추가해주고 Readme에서 연결까지 해줘"
(중간에 캠페인 스테이지 1~5 목표 스크립트 구성 요청도 있었으나, `Assets/Scripts/System/Stage1Objectives.cs`~`Stage5Objectives.cs`와 `Docs/Stage1Objectives.md`~`Stage5Objectives.md`가 이미 전부 존재해 과거 세션에서 완료된 것으로 확인 — 이번엔 추가 작업 없음)

## 조사 내용

- README.md(498줄)를 전체 정독한 결과, 사용자가 붙여넣은 체크리스트 대부분은 이미 README "구현 완료 기능"/"로드맵(미구현)" 섹션에 반영돼 있었음(도달/추격 로직 통일, 언덕 처리, 히트박스, 스킬 우선순위, 자원 반납 로직, 영토/점령 시스템 등).
- 다만 최근 `doc/0552`~`doc/0577` 구간(EnemyAIDirector/AllyAIDirector 세부 동작, Fog of War 부분 발견, 구조 유닛 인구수, 순찰/랠리 버그 등)의 상당수가 README엔 아직 반영되지 않은 상태였음 — 관련 `doc/` 파일을 확인해 최신 상태와 대조.
- 로드맵(미구현) 섹션의 "외계종족 전용 공격/사망 이펙트" 항목이 커밋 `b74965a`(외계종족 공격 이펙트, 사운드 추가)로 이미 완료됐는데 항목이 갱신되지 않고 남아있던 것을 발견 — 완료로 이동.
- `Assets/Scripts`의 전체 `.cs` 파일명과 `Docs/*.md` 파일명을 diff해서 문서 없는 스크립트를 찾음 — 대부분(`EffectPlayer`, `HoverBob`, `TerritoryZone` 등)은 이미 README 표에 `doc/NNNN` 세션 로그로 링크돼 있었고, 진짜 미문서화 상태였던 건 `GraphicsSettingsPanel`(해상도 설정, doc/0501에서 코드 작성됐지만 Docs/README 반영 누락)과 `CylinderBoxColliderGenerator`(콜라이더 생성 에디터 유틸) 2개뿐이었음. `ResourceController.cs`는 README에 이미 "미사용 빈 스텁"으로 명시돼 있어 제외.
