## 요청 내용

사용자가 그동안 진행한 작업의 체크리스트(대부분 ✓ 완료 표시, 일부 미착수 항목 포함)를 통째로 붙여넣고 요청:

## 조사 내용

- README.md(531줄)를 전체 정독. 붙여넣은 체크리스트 대부분(벽면 건설 차단, 도달/추격 로직 통일, 스킬 우선순위, 일꾼 반납 로직, 사운드 3종, 로컬라이제이션, 해상도, 각종 버그수정 등)은 이미 "구현 완료 기능"/"로드맵" 섹션에 반영돼 있었음 — `doc/0578` 세션 이후 최근 `doc/0592`~`doc/0613` 구간만 미반영 상태였음.
- `Assets/Scripts`의 전체 `.cs` 파일(105개)과 README "핵심 스크립트" 표를 diff — README에 전혀 언급이 없던 스크립트 3종 발견:
  - `Assets/Scripts/Effects/UnitSilhouette.cs` (doc/0592~0598)
  - `Assets/Scripts/System/RescueBeaconSystem.cs` (doc/0609)
  - `Assets/Scripts/System/SubStage1Objectives.cs`~`SubStage4Objectives.cs` (doc/0606) — 4개 전부 표에서 누락
  - 각각 `Docs/*.md` 상세 문서는 없었으나, `doc/0598`(실루엣 시스템 정리), `doc/0609`, `doc/0606`이 이미 스크립트 구조를 충분히 설명하고 있어 새 `Docs/*.md`를 쓰는 대신 기존 관행(표 157번째 줄 안내문)대로 `doc/` 세션 로그로 링크.
- 로드맵 섹션의 "서브 스테이지 구성 — 씬/스크립트 구현은 아직 착수 전(doc/0602)" 문구가 stale 상태였음 — 실제로는 목표 스크립트(doc/0606)와 미션 선택 버튼(doc/0607)까지 이미 완료, 남은 건 씬 배선뿐이라 문구를 갱신.

- "일꾼이 건물 우클릭 건물 수리 기능", "유닛 체력 회복. 치유유닛 추가"는 체크 없는 신규 항목이라 로드맵에 추가. "지원기 공중(마법유닛) 공격X 추가"는 기존 로드맵의 "지원기(Support Ship) 유닛" 항목과 동일 개념이라 중복 추가하지 않음.

- 붙여넣은 체크리스트 중 doc 번호 확인이 안 된 최근 항목들(`doc/0605` 미션 선택 툴팁 행성 이름, `doc/0608` PlacementSystem 스폰 온오프 필드, `doc/0610`/`0611` EnemyAIDirector 공격 레인, `doc/0612` 추적 교착 버그 수정)도 README에 전혀 반영되지 않은 상태였어서 함께 추가.
