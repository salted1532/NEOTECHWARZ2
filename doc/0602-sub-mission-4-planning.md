## 추가 조사 (목표 형식 확정용)

- `StageManager`(`Assets/Scripts/System/StageManager.cs`)는 승패 판정을 직접 하지 않고 각 스테이지 스크립트가 `ReportVictory()`/`ReportDefeat()`를 호출하는 방식 — "본진(MainBase) 파괴 = 패배" 같은 규칙이 엔진에 하드코딩돼 있지 않다. 즉 **본진 없이 주어진 유닛만으로 시작하는 미션도 구조적으로 문제없이 성립** (패배 조건만 "주어진 부대 전멸"로 새로 정의하면 됨 — 이건 Stage1의 "적 건물 리스트 변화 감지"와 동일한 패턴을 아군 유닛 리스트에 적용하는 정도라 구현 부담이 작음).
- `Stage2Objectives.FindNearestWorkerInRange()`(`Assets/Scripts/System/Stage2Objectives.cs:97`)는 `CompareTag("Worker")`로 일꾼만 골라 유물을 들게 함 — 서브2를 "주어진 유닛"으로만 구성하려면 그 프리셋 부대 안에 최소 1기의 Worker 태그 유닛이 포함되어야 기존 획득·운반 메커닉을 그대로 재사용할 수 있음(별도 코드 수정 없이 가능).
- `EnemyAIDirector`(`Assets/Scripts/System/EnemyAIDirector.cs`)에 이미 시간 기반 웨이브 시스템(`waveTimes` 리스트, 점점 강해지는 `attackWaves` 구성, 마지막 두 웨이브 간격만큼 계속 반복)이 구현돼 있음 — 서브4의 "20분 버티기" 디펜스는 이 웨이브 스포너를 그대로 쓰고, 20분 타이머가 끝나면 `ReportVictory()`, 방어 부대/거점이 전멸하면 `ReportDefeat()`를 호출하는 아주 작은 목표 스크립트 하나만 새로 추가하면 됨. 완전히 새로운 시스템이 아니라 기존 웨이브 스포너 + `StageManager` 보고 패턴의 재조합.

## 배치 방식 확정 (사용자 피드백 반영)

최초 제안은 스테이지 "사이(전환부)"에 서브 미션을 끼워 넣는 방식이었으나, 사용자가 스테이지 1~4 각각에 서브 미션 1개씩을 짝지어 붙이는 구조(1-서브1, 2-서브2, 3-서브3, 4-서브4)를 원한다고 확정. 이에 따라 각 서브 미션을 "두 스테이지 사이"가 아니라 **해당 메인 스테이지와 같은 시간대·같은 무대에서 벌어지는 병행 작전**으로 재구성.

**설계 원칙**
- 서브1·2·4는 **본진/생산/자원 채취 없이 프리셋 부대만으로 클리어**하는 형식으로 통일 — 짧고 밀도 높은 사이드 미션이라는 성격에 맞고, 패배 조건도 "본진 파괴" 대신 "주어진 부대 전멸"로 일관되게 정의.
- 서브3만 예외적으로 **본편과 동일한 기지+자원 채취+생산 구조**를 그대로 사용 — 목표 목록에는 "부수기"가 없지만(구조가 유일한 목표), 구조 지점까지 가려면 자원을 모아 병력을 뽑고 전투로 길을 뚫어야 하므로 4개 중 가장 본편에 가까운 스케일의 서브 미션이 됨. 서브1·2·4(프리셋 소규모 병행 작전)와 대비되는 "본격 확장판" 성격.
- 서브4는 "디펜스 20분"이라는 새로운 목표 형식이지만, 기존 `EnemyAIDirector` 웨이브 스포너 + `StageManager` 보고 패턴을 재조합하는 수준이라 새 시스템을 통째로 만들 필요는 없음.
- 각 서브 미션은 해당 메인 스테이지와 **같은 무대·같은 시간대**에서 벌어지는 "별동대 시점" 병행 작전 — 메인 스테이지의 서브목표(예: 미션1의 "레이더 기지 점령")를 별동대 임무로 확장하는 식으로 자연스럽게 연결됨.
- 미션 선택 화면에서 각 스테이지 버튼에 서브 미션 버튼을 함께 노출하는 방식(예: `Mission1` 옆에 `Mission1_Sub`)이 "1-서브1, 2-서브2..." 짝 구조와 가장 자연스럽게 맞음 — 세부 UI/씬 구성은 실제 구현 시점에 다시 결정.

## 최종 반영 내용 (Docs/Campaign.md)

미션 1~4 각 섹션 뒤에 "### 서브미션 N : ..." 절을 추가 — 컨셉 요약 한 문단 + 브리핑 대사 + 메인/서브 목표. 세계관 문단 아래에도 서브미션 존재를 알리는 한 줄 안내 추가.

- **서브미션 1 (측면 기습, 미션1 병행)**: 기지 없이 프리셋 전투부대로 레이더 기지 파괴. 별동대 전멸 시 실패.
- **서브미션 2 (잔해 수색, 미션2 병행)**: 기지 없이 전투유닛+일꾼 1기로 유물 파편 확보·운반.
- **서브미션 3 (구조대 파견, 미션3 병행)**: 본편과 동일한 기지+자원+생산. 저항을 뚫고 흩어진 생존자 전원 구조가 유일한 목표(파괴 목표 없음).
- **서브미션 4 (최후의 저지선, 미션4 병행)**: 기지 없이 고정 방어부대로 20분간 웨이브 방어.
