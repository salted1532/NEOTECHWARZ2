# 0347 — 버그 수정: 건물 따라가기로 겹친 공중 유닛이 영원히 안 풀림

## 요청

사용자 보고: 공중 유닛이 건물 우클릭(따라가기 모드)으로 겹친 상태에서, 그 상태 그대로 공격 명령이나 다른 곳으로 이동 명령을 내리면 공격 중이거나 목적지 도착 시 겹침이 풀려야 하는데 안 풀림. 다시 드래그로 선택해서 이동/공격 명령을 내려야만 풀림. 추가 확인: 겹친 상태에서는 서로 밀어내는 힘 자체가 작동하지 않고, 유닛 하나를 떼어내고 다시 이동 명령을 내리면 그제서야 나머지가 서로 밀어냄.

## 원인

`Assets/Scripts/Unit/UnitController.cs`의 `SeparateFromOverlappingAirUnits()`가 두 유닛 사이 거리(`dist`)가 `0.001f`보다 클 때만 분리 힘을 적용했음 (`dist > 0.001f && dist < requiredDist`).

건물 따라가기(`FollowBuilding`)로 여러 공중 유닛이 같은 건물의 `GetClosestSurfacePoint`(동일 좌표)로 수렴하면, 서로 완전히 같은 좌표(또는 그에 매우 가까운 좌표)에 도착하게 된다. 이때 `diff = transform.position - other.transform.position`이 거의 0벡터가 되어 `diff.normalized`도 0벡터가 되고, 그 결과 미는 힘(push)이 영원히 0으로 계산됨 — 몇 번을 재이동/재공격해도 매 프레임 똑같은 0 힘이 나오는 안정적인(그러나 잘못된) 평형 상태였음.

유닛 하나를 수동으로 드래그해서 떼어놓으면 그 유닛만 다른 유닛들과의 거리가 0이 아니게 되어 분리가 정상 작동하기 시작했던 것 — 즉 분리 로직 자체는 정상이고, "완전히 같은 좌표에 겹친 경우"만 처리가 빠져 있었음.

## 변경 내용

- `dist > 0.001f` 조건을 제거하고, `dist <= 0.001f`(거의 완전히 겹친 경우)일 때는 `diff.normalized` 대신 새로 추가한 `StackedNudgeDirection()`(유닛의 `GetInstanceID()` 기반 고정 방향, 매 프레임 동일)을 사용하도록 수정.
- `StackedNudgeDirection()`을 `SeparateFromOverlappingAirUnits()` 옆에 추가 (`GetInstanceID()`는 Unity에서 최근 deprecated 처리되어 대신 `GetHashCode()` 사용 — Unity Object는 이것도 인스턴스ID 기반이라 동일하게 동작하면서 경고는 없음).

이제 완전히 겹친 유닛도 항상 0이 아닌 방향으로 밀려나기 시작해서, 몇 프레임 안에 정상적인 반경 기반 분리로 자연스럽게 넘어감.

## 비고

3기 이상이 정확히 같은 좌표에 겹친 경우 인스턴스ID 기반 방향이 서로 다른 유닛끼리 우연히 비슷한 각도로 겹칠 수 있어(예: 두 유닛이 거의 같은 방향으로 밀려나 잠깐 다시 스치는 정도) 완벽한 원형 분산은 아니지만, "영원히 안 풀리는" 핵심 버그는 해결됨. (ponytail: 인스턴스ID 각도는 결정론적 유사난수일 뿐 균등 분산은 아님 — 대규모 스택에서 여전히 어색하면 페어별 골든앵글 분산으로 교체)
