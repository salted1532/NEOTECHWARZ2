# 0379 - 지형 스캔 간격을 더 촘촘하게 조절

**날짜:** 2026-08-03

**승인 후 구현 완료.** `terrainSampleStep` 0.5m → 0.2m로 변경.

## 검증

- `npx uloop-cli compile`: `Success: true`, 에러 0개, 경고 33개(기존과 동일 - 새로 생긴 경고 없음).

## 요청 내용

> 맵 바깝으로 걸친 부분이 있는경우 잘 막히는 부분도 있는데 안막히는 부분도 있네 조금더 촘촘하게
> 스캔하는게 좋을거 같아

## 조사 결과

- [[0378]]에서 "표본 지점이 지형을 못 맞히면 배치 불가"로 바꿔서 맵 바깥 돌출을 감지하게 했지만,
  표본 간격(`terrainSampleStep`, `PlacementSystem.cs:491`)이 0.5m라서 그보다 얇게(0.5m 칸 사이로)
  걸치는 돌출은 표본 사이를 그대로 빠져나가 여전히 감지가 안 됨 - [[0377]]의 "열린 질문"에서 이미
  예상했던 한계.
- 코드 로직 자체는 이미 맞게 고쳐져 있으므로, 표본 간격 값만 줄이면 됨(`[SerializeField]`라 코드
  변경 없이 인스펙터에서 바꿔도 되지만, 기본값 자체를 낮춰서 별도 설정 없이도 촘촘하게 동작하도록
  코드에서 바꿔달라는 요청으로 해석).

## 코드 변경 (제안)

기존 코드 (`PlacementSystem.cs:488~491`):
```csharp
    [Header("지형 평탄도 검사 (절벽/벽면 건설 방지)")]
    [Tooltip("건물이 차지하는 풋프린트 전체를 이 간격(미터)으로 촘촘히 스캔해 지면 높이 최고-최저 차이를 " +
             "구한다. 값이 작을수록 절벽이 살짝만 걸쳐도 놓치지 않지만 레이캐스트 횟수가 늘어난다.")]
    [SerializeField] private float terrainSampleStep = 0.5f;
```

변경 코드:
```csharp
    [Header("지형 평탄도 검사 (절벽/벽면 건설 방지)")]
    [Tooltip("건물이 차지하는 풋프린트 전체를 이 간격(미터)으로 촘촘히 스캔해 지면 높이 최고-최저 차이를 " +
             "구한다. 값이 작을수록 절벽이 살짝만 걸쳐도 놓치지 않지만 레이캐스트 횟수가 늘어난다.")]
    [SerializeField] private float terrainSampleStep = 0.2f;
```

## 열린 질문

- 0.2m도 임의 추정치 - 이번에 놓친 돌출 폭이 정확히 얼마인지 몰라서 넉넉히 더 줄임(0.5m → 0.2m,
  스텝 수는 가로/세로 각각 약 2.5배로 늘어남 - 예: 4m x 4m 건물 기준 라캐스트 수가 약 81회 →
  441회). 그래도 안 막히는 경우가 남으면 더 낮추거나(예: 0.1m), 매 표본이 아니라 건물 테두리
  전체를 따라 도는(윤곽선 기반) 별도 방식으로 바꾸는 걸 고려해볼 수 있음.
