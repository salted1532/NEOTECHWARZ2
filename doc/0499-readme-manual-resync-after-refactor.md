# 0499 — 리팩토링 후 README/게임설명서 재동기화

**날짜:** 2026-08-09

## 요청 내용

"현재 변경된 스크립트를 포함해서 한번더 전체 스캔해서 Readme.md파일 갱신해줘 그리고 게임 설명서도
변경할 필요있는건 수정해줘"

## 조사 내용

doc/0498(전체 스크립트 리팩토링) 이후 재스캔한 결과:

1. **리팩토링 자체(Tier 1~4, 15건 적용)는 버그 수정/죽은 코드 제거/성능 최적화뿐** — 사용자 요구대로
   기존 기능을 그대로 유지했으므로 README/게임설명서에 새로 반영할 "기능"은 없음(내부 구현 디테일이라
   README 표에도 개별 메소드 단위로는 안 나와 있어 영향 없음).
2. 다만 이 세션 사이에 **동시에 진행되던 다른 세션의 작업**(doc/0493~0496 - Ore/Gas 자원 명칭 재정의
   "아이로나이트 광석"/"페트로나이트" + 로컬라이제이션 구현, Docs/SporeBrood.md·Docs/ResourceSystem.md
   등록)이 README의 Docs 링크 목록에는 반영됐지만, **"구현 완료" 체크리스트와 게임설명서 본문에는
   아직 반영되지 않은 상태**였음 - 실제 `ResourceNode.cs`/로컬라이제이션 JSON까지 확인해 코드로
   구현됐음을 재확인.
3. `Docs/*.md` 파일 전체와 README 스크립트 표/문서 링크를 다시 대조 - 빠진 항목 없음(Stage1~5는 기존
   "외" 표기로 통합 링크됨).
4. 재스캔 중 이번 세션과 무관한 **기존 오기(stale 정보)**도 발견: README에 "1스테이지 맵 복원 —
   `TestScene` 씬 + `Mission1` 프리팹...(`Mission2~5` 프리팹은 아직 미사용, 캠페인 맵은 추후 별도
   제작 예정)"이라는 문구가 남아있었는데, 실제로는 `Assets/Scenes/Missions/Mission0`~`Mission5` 씬과
   `Maps/Mission0`~`Mission5` 프리팹이 전부 존재하고 사용 중임을 확인(같은 파일의 "캠페인 기획 및
   스테이지 0~5 구성 완료" 항목과 모순되던 옛 문구).

## 변경 내용

### `README.md`
- **로컬라이제이션 체크리스트**에 자원 노드 명칭·설명 번역 항목 추가: `[x] 자원 노드(광물/가스)
  명칭·설명 번역 — 기존 "Ore"/"Gas"를 세계관에 맞게 "아이로나이트 광석(Ironite Ore)"/"페트로나이트
  (Petronite)"로 재정의(doc/0493), resource.ore/gas.name/desc 키 체계로 Info Panel에 이름+로어 설명
  표시(doc/0494)`
- **프로젝트 구조 트리**: `맵 프리팹(Maps/Mission1~5, 실제 사용 중인 건 Mission1뿐)` →
  `맵 프리팹(Maps/Mission0~5, 캠페인 스테이지 0~5 씬이 각각 대응하는 프리팹을 사용)`
- **그래픽/비주얼 체크리스트**: 낡은 "1스테이지 맵 복원(Mission1만, Mission2~5 미사용)" 항목을
  "캠페인 스테이지 0~5 맵 전체 제작 완료" 항목으로 교체(다른 섹션의 캠페인 완료 기록과 중복/모순
  해소).

### `게임설명서.md`
- **5. 자원과 인구수** 섹션: "광물(Ore)"/"가스(Gas)" 명칭을 실제 게임에 반영된 "아이로나이트
  광석(Ironite Ore)"/"페트로나이트(Petronite)"로 교체하고 각각 한 줄 로어 설명 추가, 자원 노드
  선택 시 Info 패널에 이름+설명이 표시된다는 안내 문장 추가.
- 그 외 "광물·가스"(117번 줄, 자원 비용 안내)와 스테이지 목표의 "광물 1000/2000 확보"(207/217번 줄)는
  일반 자원 총량을 가리키는 범용 표기라 그대로 유지(README의 `Docs/ResourceSystem.md` 링크 설명과
  동일하게 신규 로어 이름과 기존 약칭을 병행 표기하는 패턴).

## 요약 / 남은 작업

리팩토링(doc/0498) 자체는 기능 변화가 없어 문서 갱신 대상이 아니었고, 실제로 갱신이 필요했던 부분은
(1) 동시 진행 중이던 자원 명칭 재정의 세션의 문서 반영 누락, (2) 캠페인 맵 완성 이전에 쓰여진 낡은
문구였음. 둘 다 이번 세션에서 수정 완료. 코드/에셋 변경 없음 — 문서 전용 세션.
