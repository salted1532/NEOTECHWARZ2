# ItemHover

`Assets/Scripts/Animation/ItemHover.cs`

## 개요

조건/상태 판정 없이 붙이기만 하면 계속 위아래로 둥실거리고 천천히 회전하는 순수 장식용 컴포넌트. 공중 유닛/리프트 건물 상태를 판정해서 재생 여부를 결정하는 `HoverBob`과 달리, 미션 아이템(유물 등)처럼 "그냥 항상 떠 있어야 하는" 오브젝트에 붙인다.

## 주요 필드

| 필드 | 설명 |
|---|---|
| `bobHeight` / `bobDuration` / `bobEase` | 위아래 이동 폭, 한쪽 방향 이동 시간, 이징 |
| `rotationDuration` | Y축 한 바퀴(360도) 도는 데 걸리는 시간 |

## 메소드

| 메소드 | 설명 |
|---|---|
| `Start()` | 현재 Y 위치를 기준으로 위/아래 요요 트윈과, 무한 반복하는 Y축 회전 트윈을 시작 |
| `OnDestroy()` | `transform.DOKill()`로 트윈 정리 |

## 연관 컴포넌트

- **MissionItem**: 유물/연구 데이터 등 이 컴포넌트가 붙는 대표적인 오브젝트
- **HoverBob**: 상태 판정이 필요한 공중 유닛/리프트 건물용 대응 컴포넌트(이 스크립트는 무조건 재생되는 단순 버전)
