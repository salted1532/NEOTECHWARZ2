# 적 진영(OC) 유닛/건물 수치 정리

> 최종 갱신: 2026-07-29
> 아군(NTA) 쪽 `Docs/UnitAndBuildingStats.md`와 동일한 형식. 값 출처는 `Assets/Scripts/ScriptableObject/Data/OC Unit Data SO.asset` / `OC Building Data SO.asset`(`EnemyUnitDataSO`/`EnemyBuildingDataSO`)과, SO에 없는 필드(방어력/공격 방식/공중 여부/고유 보너스)는 각 유닛·건물 프리팹의 `EnemyUnitController`/`EnemyBuildingController` 값을 그대로 옮겨왔다. `doc/0232`에서 `EnemyUnitController.Start()`/`EnemyBuildingController.Start()`가 스스로 자기 ID로 SO를 조회해 적용하므로, 씬에 직접 배치됐든 나중에 스포너로 생성됐든 SO 값이 실제 게임 값과 동일하다(아군과 달리 `enemyUnitID`/`enemyBuildingID`가 SO ID와 전부 일치 — 아군 쪽에 있던 Sharpshooter/SkyLancer 같은 ID 불일치 버그가 여기엔 없음).

## 데미지 시스템 (참고, 아군과 동일)

**장갑 타입** — 유닛의 고유 추가 데미지가 노리는 대상을 구분: 경장갑(보병/경차량), 중장갑(전차/대형유닛)

**크기 타입** — 공격 방식별 데미지 배율을 결정: 소형 / 중형(배율 보정 없음) / 대형

**공격 방식별 크기 배율** (`DamageMultiplierTable.asset`, 아군·적 공용):

| 공격 방식 | 소형 | 중형 | 대형 |
|---|---|---|---|
| 소총 | 100% | 80% | 60% |
| 폭발 | 70% | 100% | 130% |
| 레이저 | 100% | 100% | 100% |
| 화염 | 130% | 100% | 60% |

최종 데미지 = `공격력 × 크기 배율 × (대상이 고유보너스 대상 장갑타입이면 1+보너스%) → 반올림 → 대상 방어력 감산 → 최소 1 보장`. 아군과 달리 연구소(Lab) 전역 공격/방어 연구 보너스는 적용되지 않는다(OC 쪽 연구 시스템 없음, `EnemyUnitController.CalculateFinalDamage` 주석 참고).

⚠️ **적(OC)은 아군과 달리 지상/공중 공격 도메인 제약이 실제로 구현되어 있다.** `EnemyAttackRange.CanEngage()`가 `canAttackGround`/`canAttackAir` 값으로 대상을 사전에 걸러내므로, 아래 "공격 가능 대상"은 실제 게임 동작이다(아군 `AttackRange`는 이 제약이 없이 태그만 본다).

## 참고/미구현 사항

- **적 AI는 아군보다 단순하다.** `EnemyUnitController`는 자동 교전(사거리 내 감지), 이동, 공격-이동만 지원 — 지정 대상 강제 추격, 건설/채집, 특성 스킬 발동, 진형 등은 없음(`EnemyUnitController.cs` 상단 주석).
- **적(OC)은 아군과 달리 지상/공중 공격 도메인 제약이 실제로 구현되어 있다.** (`EnemyAttackRange.CanEngage`) — 위 데미지 시스템 섹션 참고.
- **Ironhawk의 `isAirUnit`이 아직 0(지상)**이라 설계(대공 전문 공중유닛)와 달리 실제로는 지상 유닛처럼 이동한다. 프리팹에서 직접 고쳐야 한다.
- **Ironhawk의 특성(트레이트) 2종은 SO에 데이터만 있고 미구현.** `EnemyUnitController`가 `traitA`/`traitB`를 아예 조회하지 않는다(아군 쪽 트레이트 시스템은 `UnitController`에 있지만 적 쪽엔 대응 코드가 없음).
- **레일거너의 "뉴럴 랩 필요" 생산 조건이 실제로 강제되는지 미확인.** SO에 `requiredBuildingID: 6`은 있으나, 적 유닛 생산 큐 자체가 캠페인 스크립트/트리거 스폰 방식이라(건물이 생산 큐를 갖지 않는 "껍데기") 이 값을 검사하는 코드가 실제로 존재하는지는 별도 확인이 필요하다.
- 아군 쪽 상세 대조표(설계 값 vs 실측)는 `Docs/UnitBalanceReference.md` 참고. 적 쪽은 `doc/0230`(진영 구성 제안)~`doc/0250`(건물 GroundLayer 수정)에 설계·구현 히스토리가 있다.
